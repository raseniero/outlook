# Introducing GPT-5.5 — A new class of intelligence for real work

OpenAI is introducing **GPT-5.5**, their smartest and most intuitive to use model yet. GPT-5.5 is now available in the **API, Codex, and ChatGPT**.

GPT-5.5 understands what you're trying to do faster and can carry more of the work itself. *It also uses significantly fewer tokens to complete the same tasks*, making it more efficient as well as more capable.

To migrate, use the API [prompt guide](https://developers.openai.com/api/docs/guides/prompt-guidance) and [migration guide](https://developers.openai.com/api/docs/guides/latest-model), or run `$openai-docs migrate this project to gpt-5.5` to kick off a Codex migration plan.

GPT-5.5 is now the **default model in Codex**.

## Key Capabilities

- **Agentic coding:** Strongest agentic coding model to date — implementation, refactors, debugging, testing, validation.
- **Knowledge work:** With Codex computer-use skills, can see screen, click, type, navigate interfaces, move across tools.
- **Scientific & technical research:** Better at persisting across the explore → gather → test → interpret loop than other models.
