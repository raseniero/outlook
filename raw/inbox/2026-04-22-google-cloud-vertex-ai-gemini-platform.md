# Vertex AI is now part of Gemini Enterprise Agent Platform

Hi Ramon,

Vertex AI's capabilities are now part of Google Cloud's new **Gemini Enterprise Agent Platform**. Your favorite model and agent-building tools have a new home — now with exciting new features and zero disruption to your existing workflows.

## New Features

**Agent Runtime**
The revamped Runtime offers sub-second cold starts and provisions new agents in seconds, enabling agents to manage complex, multi-step workflows and deep reasoning tasks requiring extended persistence.

**Agent Memory Bank**
Memory Bank curates long-term memories from conversations. New Memory Profiles offer high-accuracy recall, ensuring your agents maintain context across interactions.
