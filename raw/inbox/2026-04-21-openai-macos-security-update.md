# Action Required: Security update for OpenAI macOS apps

> Please update any OpenAI macOS apps **before May 8, 2026**.

## Background

As shared in OpenAI's recent blog post, and as a **precautionary security measure** following the recent compromise of **Axios**, a third-party developer library, the OpenAI security team has **rotated code signing material** for all OpenAI macOS apps including:

- ChatGPT
- Codex
- Codex CLI
- Atlas

OpenAI found **no evidence** that user data was accessed, that their systems were compromised, or that software was altered. This is purely precautionary.

**iOS, Android, and Windows applications are not affected.**

## What to do

If you use any of these on macOS, update to the minimum latest versions by **May 8, 2026**:

- ChatGPT Desktop
- Codex App
- Codex CLI
- Atlas
