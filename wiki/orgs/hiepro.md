# Hawaii eProcurement System (HIePRO)

**Type:** Hawaii state procurement platform — recurring source of business-opportunity solicitations matched on Jairosoft's commodity-code subscription.
**Sender:** `hiepro@ehawaii.gov` · Support: `hiepro@hawaii.gov` · 808-586-0554

## Overview

HiePro publishes RFQs / solicitations from Hawaii state agencies. Jairosoft subscribes to a commodity-code profile that triggers notifications matched to its capabilities (system integration, software services). At least 6 original solicitation notices and 2 follow-up Q&A notices have arrived in the indexed corpus 2026-04-20 -> 2026-05-05:

- **P26002383** — System Integrator Services for a Captive Insurance Solution (Oahu) — 2026-04-20.
- **P26002421** — ES2016-26 Airports Interactive Terminal Maps System (Statewide) — 2026-04-20.
- **Q26002444** — Investment Management Software and Product Support Services (Oahu) — 2026-04-21.
- **Q26002479** — Check Point Technical Support Services, Oahu — 2026-04-23.
- **P26002371** — Enterprise Financial System (EFS) Transition Readiness Support, Statewide — 2026-04-24.
- **Q26002498** — Endpoint Device Maintenance, Hansen's Disease Branch (Oahu, Molokai) — 2026-04-24.
- **P26001887** — Facilities & Academic Course Scheduling & Optimization, Statewide — surfaced via Q&A answers notice on 2026-04-27.
- **P26002329** — Financial Budgeting, Planning and Management Software Solution, Hawaii — surfaced via Q&A answers notice on 2026-05-05.

Each requires a bid / no-bid decision from Jairosoft.
